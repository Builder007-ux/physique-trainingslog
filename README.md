# Physique Trainingslog

Trainingslog für Kraft- und Muskelaufbau: Abhaken pro Trainingstag, PR-Liste, Verlaufsgraphen und Plan.

Die Seite läuft im Browser und lässt sich über „Zum Home-Bildschirm hinzufügen“ installieren. Die Einträge werden in einem Supabase-Projekt gespeichert und sind nach der Anmeldung auf allen Geräten verfügbar.
